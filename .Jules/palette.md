## 2025-05-14 - [Accessibility in Cloned DOM Environments]
**Learning:** This project implements dark mode by cloning the entire `.container` into a `#dark-container` for a clip-path transition. This results in duplicate interactive elements in the DOM. ARIA labels and focus indicators must be robust enough to work across both containers.
**Action:** When adding accessibility features or event listeners, use class-based selectors or event delegation (e.g., `event.target.closest`) to ensure the behavior is consistent in both the original and cloned containers.
## 2026-07-06 - [Global Focus Visibility & Localized ARIA Labels]
**Learning:** In a UI where the mouse cursor is hidden globally, high-contrast `:focus-visible` indicators are the only visual feedback for navigation. Furthermore, when using a custom JS-based localization system, accessibility attributes (ARIA labels, titles) must be synchronized dynamically to ensure screen reader users receive the correct context in their selected language.
**Action:** Always implement a global `:focus-visible` rule and integrate `data-i18n-aria-label` and `data-i18n-title` attributes into the `updateLanguage` loop to maintain parity between visual and accessible content.
